# Design Tokens

Extracted from Figma `Valiify-Dashboard-Component-Library` via the Figma MCP
`get_variable_defs` tool. This page exists to be compared side by side with the
Figma variables panel — every swatch and specimen below should match.

Tokens live in a Tailwind `@theme` block in `src/themes/valiify.css`, which is
**generated** from `tokens/figma-tokens.json` by `scripts/build-theme.mjs`.
Regenerate with `npm run build:theme`.

Colors are stored as OKLCh; the hex shown here is the original Figma value. The
generator asserts every conversion round-trips back to its source hex within
1/255 per channel, so the two are equivalent.

## Focus ring

The shared affordance for tabbing between interactive elements, from Figma
**Menu Item → Ring**. Applied via the `focus-ring` utility on `:focus-visible`,
so it appears for keyboard navigation but not on mouse clicks.

The ring's outer edge aligns with the component's **own** outer edge rather than
sitting outside it — in Figma it is a full-size overlay frame, reproduced here
with a negative `outline-offset`. Because `outline` follows `border-radius`, the
ring needs no radius of its own and picks up whatever the component sets.

<div
  style={{
    display: "flex",
    gap: 28,
    alignItems: "flex-start",
    flexWrap: "wrap",
    margin: "16px 0 12px",
  }}
>
  {[
    ["rounded-control", "var(--radius-control)", "buttons, inputs"],
    ["rounded-surface", "var(--radius-surface)", "cards, panels"],
    ["rounded-pill", "var(--radius-pill)", "pills, avatars"],
  ].map(([label, r, use]) => (
    <div key={label} style={{ textAlign: "center", fontSize: 11 }}>
      <div
        style={{
          width: 148,
          height: 40,
          borderRadius: r,
          background: "var(--color-surface-paper)",
          outline: "var(--ring-focus-width) solid var(--ring-focus-color)",
          outlineOffset: "calc(-1 * var(--ring-focus-width))",
          marginBottom: 8,
        }}
      />
      <code style={{ fontSize: 10 }}>{label}</code>
      <div style={{ color: "var(--color-content-tertiary)", marginTop: 2 }}>
        {use}
      </div>
    </div>
  ))}
</div>

| Token                | Value     | Figma                                       |
| -------------------- | --------- | ------------------------------------------- |
| `--ring-focus-width` | 2px       | raw value on the Ring frame, not a variable |
| `--ring-focus-color` | `#1e4d8c` | `Primary/Main`                              |

The 2px width is a **raw value** in Figma rather than a bound variable, so it
carries its own token here instead of borrowing `--border-micro` — which happens
to share the value but has no stated relationship to it.

## Typography

**37 text styles.** The composite `--text-*` tokens carry font size, line height,
weight, and letter spacing in a single utility.

Two things they can **not** carry, both of which bite silently:

- **`font-family`** — the JetBrains Mono styles must be paired with `font-mono`,
  or they render in Inter.
- **`text-transform`** — the Label styles are uppercase in Figma, so use the
  generated `type-label-*` utilities, which bundle casing (and the mono family)
  into one class.

### Reading the specs

`line-height: normal` is Figma's **"Auto"** — the font's own metrics, roughly
1.21x for Inter. The Figma API reports Auto as the sentinel `100`, which does
_not_ mean 100%; treating it as `1` makes those styles noticeably too tight.

Letter spacing is in `em` because every Figma letter-spacing value is a
**percentage** of font size, not px. `10%` becomes `0.1em`.

## Spacing

**No spacing tokens are defined.** Tailwind v4's spacing scale is a multiplier of
`--spacing` (0.25rem), so Figma's whole-pixel values all map to standard steps.
Defining `--spacing-8: 8px` would make `p-8` mean 8px instead of 32px.

The multiplier must be a multiple of 0.25 (= 1px steps), so Tailwind can express
any whole pixel but no half-pixel. Figma's two fractional tokens therefore need
arbitrary values rather than a step.

| Figma       | px  | Tailwind    | Figma        | px   | Tailwind     |
| ----------- | --- | ----------- | ------------ | ---- | ------------ |
| Spacing/1   | 1   | `p-0.25`    | Spacing/11   | 11   | `p-2.75`     |
| Spacing/2   | 2   | `p-0.5`     | Spacing/12   | 12   | `p-3`        |
| Spacing/3   | 3   | `p-0.75`    | Spacing/12-5 | 12.5 | `p-[12.5px]` |
| Spacing/4   | 4   | `p-1`       | Spacing/14   | 14   | `p-3.5`      |
| Spacing/5   | 5   | `p-1.25`    | Spacing/16   | 16   | `p-4`        |
| Spacing/6   | 6   | `p-1.5`     | Spacing/20   | 20   | `p-5`        |
| Spacing/7   | 7   | `p-1.75`    | Spacing/22   | 22   | `p-5.5`      |
| Spacing/7-5 | 7.5 | `p-[7.5px]` | Spacing/24   | 24   | `p-6`        |
| Spacing/8   | 8   | `p-2`       | Spacing/28   | 28   | `p-7`        |
| Spacing/9   | 9   | `p-2.25`    | Spacing/32   | 32   | `p-8`        |
| Spacing/10  | 10  | `p-2.5`     |              |      |              |
