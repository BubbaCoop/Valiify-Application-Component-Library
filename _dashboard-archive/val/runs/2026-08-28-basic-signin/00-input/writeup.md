# Request: Dashboard sign-in page

Attached is a screenshot of the sign-in page design (design@2x.png,
captured at 2x from a 1280x800 frame).

Build the sign-in page for the Valiify dashboard:

- A centered card titled "Welcome Back" with the subtitle
  "Sign in to your Valiify Dashboard account."
- Email field (label "Email", prefilled "user@valiify.com") and Password
  field (label "Password", empty, placeholder "Enter your password").
- A "Remember me" checkbox, unchecked by default.
- Primary "Sign In" button (full remaining width) beside an outline
  "Cancel" button. Sign In and Cancel each show a confirmation alert in
  this prototype (no backend yet).
- A centered "Forgot password?" link under the buttons; destination is
  the forgot-password page (not part of this build).
- A small outline "View Demo Info" button pinned to the bottom-right of
  the viewport, which shows an informational alert.

Audience: bank reviewers signing in to the dashboard (reviewer-facing).
The email value is account data. No error/empty states are in scope for
this prototype — the design shows the default state only.
